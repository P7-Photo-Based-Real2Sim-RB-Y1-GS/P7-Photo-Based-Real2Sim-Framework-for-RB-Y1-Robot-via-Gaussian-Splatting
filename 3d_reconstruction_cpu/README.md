# SAM2-Mask-Guided RGB-D 3-Pass Reconstruction

This directory contains the CPU-only reconstruction pipeline used for the final
Real2Sim object asset generation step.

The pipeline is designed for Intel RealSense RGB-D turntable captures arranged
as three passes:

```text
object_001/
  camera_intrinsics.json
  pass_01_level/
    rgb/
    depth/
    mask_refined/
    metadata.csv
  pass_02_high/
    rgb/
    depth/
    mask_refined/
    metadata.csv
  pass_03_low/
    rgb/
    depth/
    mask_refined/
    metadata.csv
```

The masks are expected to be object masks generated by SAM2 or a compatible
segmentation tool. The script does not require a GPU.

## Method

1. Back-project masked RGB-D pixels into a 3D camera-coordinate point cloud.
2. Use the SAM2 mask and valid depth range to keep only object surface points.
3. Estimate the turntable rotation center for each pass using circle fitting.
4. Align frames inside each pass using turntable angle metadata.
5. Merge the three pass-level point clouds using candidate rotations and ICP.
6. Refine the merged cloud with scikit-learn IsolationForest and DBSCAN.
7. Generate simulation-oriented meshes with Poisson and Ball Pivoting.

This approach was selected over BundleSDF and Gaussian Splatting for this CPU
asset pipeline because it directly produces mesh outputs (`PLY`, `STL`, `GLB`)
that can be used as simulation geometry or converted into Isaac Sim assets.

## Installation

Python 3.12 is recommended.

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install --upgrade pip
& .\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

## Run

```powershell
.\run_reconstruction.ps1 `
  -Dataset "D:\datasets\object_001" `
  -Output "D:\datasets\object_001\sam2_rgbd_reconstruction" `
  -InstallRequirements
```

Python direct run:

```powershell
& .\.venv\Scripts\python.exe .\sam2_rgbd_3pass_reconstruction.py `
  --dataset "D:\datasets\object_001" `
  --output "D:\datasets\object_001\sam2_rgbd_reconstruction"
```

```text
  pass_01_level_clean.ply
  pass_02_high_raw.ply
  pass_02_high_clean.ply
  pass_03_low_raw.ply
  pass_03_low_clean.ply
```

Use `mesh_poisson_mm.stl` or `mesh_bpa_mm.stl` for millimeter-scale simulation
geometry. Use `mesh_poisson.glb` or `mesh_bpa.glb` when vertex color appearance
is needed.

## Notes on Feature-Poor Objects

Objects with smooth, low-texture, reflective, transparent, dark, or repetitive
outer surfaces are still difficult to reconstruct from RGB-D images. SAM2 masks
help isolate the object, and ML filtering removes outliers, but the pipeline
cannot recover geometric detail that is not present in the depth stream.

See [docs/FEATURE_LIMITATIONS.md](docs/FEATURE_LIMITATIONS.md) for the
experiment notes and supporting references.
